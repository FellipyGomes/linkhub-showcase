# LinkHub #

Smart digital business card platform designed for small businesses.

LinkHub enables customers to instantly access business contact channels through NFC tags or QR Codes, providing a simple and fast mobile experience.

## Features

- WhatsApp integration
- Instagram integration
- Google Reviews integration
- Website links
- Google Maps navigation
- Business hours status (Open / Closed)
- Custom branding and themes per client
- Mobile-first responsive design

## How It Works

1. The customer scans a QR Code or taps an NFC tag.
2. LinkHub identifies the business page.
3. The customer gains instant access to contact, social media, reviews, website, and directions.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Cloudflare Pages

## Project Structure

Currently, the project uses a client configuration model where each business has its own data, including:

- Name
- Logo
- Contact links
- Social media profiles
- Business hours
- Theme settings
