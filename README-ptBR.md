# LinkHub #

Plataforma de cartão digital inteligente desenvolvida para pequenas empresas.

O LinkHubb permite que clientes acessem instantaneamente canais de contato e informações do negócio por meio de tags NFC ou QR Codes, proporcionando uma experiência rápida, prática e sem necessidade de aplicativos.

## Funcionalidades

- Integração com WhatsApp
- Integração com Instagram
- Integração com Google Avaliações
- Integração com websites
- Navegação via Google Maps
- Exibição de status de funcionamento (Aberto/Fechado)
- Personalização visual por cliente
- Design responsivo com foco em dispositivos móveis

## Como Funciona

1. O cliente aproxima o celular em uma tag NFC ou escaneia um QR Code.
2. O LinkHubb identifica a página da empresa.
3. O usuário recebe acesso instantâneo aos canais de contato, redes sociais, avaliações, website e localização.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Cloudflare Pages

## Estrutura do Projeto

O projeto utiliza um modelo baseado em configuração de clientes, permitindo que cada empresa possua informações próprias, como:

- Nome da empresa
- Logo
- WhatsApp
- Instagram
- Website
- Avaliações Google
- Horário de funcionamento
- Tema visual personalizado
